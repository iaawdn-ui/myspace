# Course slide decks

Each PDF is a separate 16:9 slide deck, with one presentation slide per PDF page. The decks share the classic navy, ivory and brass visual system. AI.101 is supplied at the repository root as `AI101_Introduction_to_Artificial_Intelligence_Slides.pdf`; this folder contains the other 47 subjects, including AI.450 PROJECT.

These are designed opening/overview lecture decks (10 slides per subject), not the complete 100,000-word lecture series or every module's final slide set. They establish the subject's lecture rhythm and practical-first visual treatment for expansion into full module decks.

Rebuild the set with:

```bash
.venv/bin/python scripts/build_remaining_course_slides.py
```
