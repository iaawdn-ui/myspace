## How to Use

1. Pick a course and week from files 03–06.
2. Look up the recommended style number in `01-Presentation-Style-Prompts.md`.
3. Combine the general setup line and course prompt from `02-Course-Presentation-Style-Mapping.md` with that week's topic to generate the lecture script.
4. Record or synthesize the narration and pair with slides/visuals.

## Weekly Structure Convention
- **Week 1** — orientation and foundations
- **Weeks 2–7** — core content block A
- **Week 8** — mid-term checkpoint / synthesis
- **Weeks 9–15** — core content block B, application and integration (faith/culture integration typically placed in week 14–15)
- **Week 16** — final assessment and integration
